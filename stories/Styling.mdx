<Title>Tooltip styling</Title>

`JBTooltip` exposes variables for the standard message and CSS parts for structural customization. The examples below share the same markup and alter only the public styling API.

## Live gallery

Hover or focus any trigger to inspect its theme. Native `popover="hint"` behavior keeps one tooltip open at a time.

<Story of={StyleStories.Gallery} />

## Recommended customization

1. Set `--jb-tooltip-*` variables for spacing, width, colors, radius, and the optional tail.
2. Use `jb-tooltip::part(message)` for borders, shadows, typography, gradients, and backdrop effects.
3. Use `jb-tooltip::part(tooltip)` only when the native popover surface itself needs styling.
4. Use `jb-tooltip::part(content)` for layout around custom or slotted content.

```css
jb-tooltip.brand-tooltip {
  --jb-tooltip-bg-color: #172033;
  --jb-tooltip-text-color: #fff;
  --jb-tooltip-border-radius: 0.5rem;
  --jb-tooltip-padding: 0.625rem 0.875rem;
  --jb-tooltip-tail-bg-color: #172033;
  --jb-tooltip-tail-border-color: #40506b;
  --jb-tooltip-tail-border-width: 1px;
}

jb-tooltip.brand-tooltip::part(message) {
  border: 1px solid #40506b;
  box-shadow: 0 0.75rem 1.5rem rgb(15 23 42 / 20%);
}
```
